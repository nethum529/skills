# skills

Not all my skills, just the ones I share with friends and stuff.

## Install

Copy a folder into `~/.claude/skills/`.

`relay` has its own README in `skills/relay/`. Read it before the first relay
on a new machine.

`relay` also needs the hook in `skills/relay/hooks/`. Without it, relay only runs
when you type `/relay` yourself. See that folder's README.
